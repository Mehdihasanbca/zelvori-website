## 1. Core Pricing Philosophy

Zelvori operates on three non-negotiable commercial principles:
1. **Total Scope Transparency:** Every package has strictly documented limits (pages, screens, modules, revisions, and support hours). We eliminate the "hidden surcharge" model common in digital agencies.
2. **True Direct Cost Pass-Through:** Clients pay third-party service providers directly (domains, hosting, database clusters, SMS/OTP, payment gateway commissions, and LLM API tokens). Zelvori does not markup third-party cloud infrastructure.
3. **Engineered Milestones with Working Demos:** Clients review interactive prototypes or staged feature branches before approving project milestone invoices. Full intellectual property and repository access transfer upon final settlement.

## 3. Clear Disclosures & Pass-Through Cost Rules

1. **Third-Party Pass-Through Costs:**
   * Hosting (Vercel, AWS, GCP, Hetzner, DigitalOcean) is billed directly to the client's credit card.
   * Domains (Name.com, Cloudflare) remain registered in the client's own legal name.
   * AI/LLM API tokens (OpenAI, Anthropic, Google Gemini) are paid by the client under their own developer console.
   * Payment Gateway merchant fees (e.g. 2% on transactions) are deducted directly by Razorpay/Stripe.
2. **Warranty & Ongoing Support:**
   * Every project includes **30 calendar days of complimentary bug-fix warranty support** covering defects against the agreed written specification.
   * New features, design redesigns, or third-party API breaking changes outside the initial scope are quoted separately under an engineering retainer.
3. **Intellectual Property Handover:**
   * Zelvori delivers 100% intellectual property ownership, source code repositories, design assets, and database DDL schemas upon milestone completion and final payment.
