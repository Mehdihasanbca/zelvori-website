# Zelvori Brand Assets (Original Draft)

Official brand name: Zelvori
Current brand line: Ideas Into Digital Reality

## Files
- `zelvori-logo-light.svg` — transparent horizontal logo for light backgrounds; scalable vector.
- `zelvori-logo-dark.svg` — horizontal logo on deep navy background.
- `zelvori-logo-monochrome-light.svg` — single-colour logo for light backgrounds.
- `zelvori-logo-monochrome-dark.svg` — single-colour logo on deep navy background.

- `zelvori-logo-light-preview.jpg` — light-background visual preview for easy viewing.
- `zelvori-icon.svg` / `zelvori-icon.png` — standalone icon.
- `favicon-512.png` and `zelvori-icon.ico` — app/favicon starting assets.
